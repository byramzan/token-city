# Token City 🏙️

Браузерная коллективная 3D low-poly игра на Three.js по ТЗ `task.md`—`task8.md`.
Игровой аккаунт связывает несколько EVM-кошельков **Robinhood Chain**, владеет
одним основным домом и может отдельно купить бизнес. Project Token — ERC-20 на
Robinhood Chain (chain id 4663, тестовая сеть 46630) — служит внешним платёжным
рельсом, а внутренние Game Coins учитываются двойной записью.

Интерфейс — полностью на английском, в мультяшном «пряничном» стиле: SVG-иконки,
компактные панели, шрифт Baloo 2. Стадия мира (Stage 2 · Settlement) — глобальная
константа, одинаковая для всех. HUD прячется после нескольких секунд бездействия,
оставляя чистую диораму.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # продакшен-сборка в dist/ (для Vercel)
npm test         # экономика, ревизии и параметрическая модель дома
```

## Ключевые системы (task2)

- **Сначала дороги, потом участки** — площадь → 4 главных авеню → 3 кольцевые
  улицы с фонарями → готовые участки вдоль улиц. Районы: Old Town / Garden
  District / New Quarter × стороны света.
- **Параметрический конструктор из 8 шагов**: основание → этажность → планировка
  (Balanced / Social / Private) → материал → крыша → комплект дверей и окон →
  отличительная деталь → проверка, имя и предпросмотр день/вечер.
- **Бизнес покупается отдельно**: после строительства соседний участок остаётся
  зарезервированным. Категория и внешний вид подбираются под материал дома.
- **Композиция участка**: дом (главный объект) + строение + дворик + дорожки к
  улице и строению + 2–5 декораций в стиле материала. Автовыбор участка — по
  похожим соседям, плотности и равномерному росту районов.
- **Граф связей**: архитектурные, районные, функциональные (пекарня↔кафе…) и
  социальные (растут из визитов жителей). До 5 связей на дом. Режим графа:
  сцена затемняется, дуги подсвечиваются цветом типа, у каждой связи — объяснение,
  клик по связанному дому перелетает к нему.
- **Жители**: четыре жителя создаются после готовности дома. Hunger, Energy,
  Knowledge и Household Bond формируют спрос; без разрешённого Household Budget
  жители пользуются бесплатными городскими сервисами.
- **Цикл дня и ночи** (8 минут, настраивается): утро → день → золотой закат →
  вечер → ночь. Окна и вывески включаются постепенно и в разное время, фонари
  теплеют, вечером появляются светлячки. Первый вход — на закате.
- **Экономика**: рыночная котировка Project Token → Game Coins, раздельные
  available/pending/locked/household/promotional балансы, escrow, settlement,
  вывод и сверка резерва. Покупка у другого игрока переносит существующие монеты.

## Контент-система (task3)

- **Каталог из ~50 предметов** в трёх слоях: постоянная крипто-культура
  (GM Clock, Diamond Hands Trophy, Copium Tank, Rug Trap, DYOR Bookshelf,
  Emergency Sell Button…), недельная коллекция **Meme Reserve Week** (бочка
  Official Unofficial Oil Barrel, Strategic Meme Reserve Safe, генератор
  тикеров, сертификат Tokenized Nothing…) и поп-культурные пародии (портал в
  кладовку, Galaxy Brain Lamp, AI Slop Printer, аркада Chase the Candle).
  Никаких реальных токенов и логотипов — только оригинальные пародийные формы.
- **Недельные коллекции**: активная коллекция помечена бейджем; после даты
  окончания предметы перестают продаваться, установленные остаются с ярлыком
  «Archived» и датами (Meme History Archive). Тематические сеты по материалам
  (Cozy Trencher, CTO Workshop, Strategic Meme Reserve, Onchain Operations).
- **Дворовые сокеты**: у каждого участка 3 outdoor-слота — фонтан Exit
  Liquidity, флаг Meme Department, Touch Grass Patch, бык-статуя. Кнопка
  «Edit Yard» в карточке своего дома.
- **Точные интерьерные сокеты**: игрок выбирает заранее спроектированное поле,
  смотрит предмет в этом месте и отдельно подтверждает установку. Свободного
  перемещения нет; окна, двери, лестницы и проходы не получают ложных полей.
- **Диалоговые пузыри NPC** (§13–17): 78 разговоров на английском, 2–3
  реплики ≤42 символов, максимум 2 беседы одновременно, пауза 12–25 с,
  кулдаун повтора 10 минут. Контекст: утро/ночь, кафе и лавки, tech-дома,
  Meme Reserve, визиты в связанные дома; событийные реплики при новостройке
  и новой связи. Тон-режимы (crypto / friendly / minimal) в конфиге.
- **Fallback-модели** (§11): неизвестный предмет рендерится нейтральной
  коробкой, никаких розовых/чёрных моделей.
- **Аудит текстур** (§12): `docs/texture-audit.md` — все текстуры процедурные
  ≤512px, материалы кэшируются, интерьеры не грузятся на старте.

## Экономика и кошельки (task4)

- EVM-кошельки через EIP-6963 и EIP-1193: Robinhood Wallet, MetaMask,
  Coinbase Wallet, OKX, EVM-аккаунты Phantom и Backpack, плюс WalletConnect;
- до пяти проверенных кошельков у одного аккаунта с ролями login/pay/withdraw;
- неизменяемый журнал, идемпотентные операции, escrow и безопасный refund;
- отдельный Household Budget, автоматические покупки по умолчанию выключены;
- магазин чужого бизнеса показывает цену, комиссию и чистую сумму продавца;
- дневные лимиты финансирования/вывода и защищённая конфигурация токена;
- сниженный дальний fog, плавное WASD-движение и процедурная 2.5D-трава.

## Редактор дома (task5)

- версия схемы, локальные координаты и стабильные ID для дома, этажей, комнат,
  стен, проёмов, лестницы, зон и объектов;
- Ground Floor и Second Floor редактируются одинаково;
- режимы Isolate, Ghost Below, Stacked Preview и Cutaway;
- отдельные visual/collision/clearance/interaction bounds для каталога;
- точные авторские сокеты, обязательный preview/confirm и undo/redo;
- структурная и cross-floor валидация с конкретными сообщениями;
- атомарные сохранения с base revision и idempotency key;
- миграция старых слотов с резервной копией и возвратом неподходящих предметов.

  ledger.js     — двойная запись, escrow, settlement, refund и reconciliation
  market.js     — защищённые котировки, финансирование и вывод
  chain/        — обнаружение EVM-кошельков, EIP-1193 сессия, клиентский chain service
  walletProviders.js — снятый с эксплуатации реестр Solana-кошельков (история)
  houseModel.js — версия HouseDefinition, зоны, валидация и миграция
  tween.js      — мини-движок анимаций
  audio.js      — звуки UI + эмбиент (ветер, птицы, музыка)
  icons.js      — мультяшный набор SVG-иконок
  house.js      — процедурные дома v2 + общественные строения
  items.js      — ~50 процедурных моделей предметов + fallback-коробка
  dialogues.js  — 78 диалогов NPC + движок речевых пузырей
  city.js       — уличная сеть, участки, дворовые сокеты, граф, день/ночь
  residents.js  — потребности, разрешения, бесплатные сервисы и торговые маршруты

Ограничение «один основной дом на игровой аккаунт» включено. Дополнительный
связанный кошелёк не создаёт новый дом и не выдаёт повторную стартовую награду.

## Robinhood Chain: тестовая сеть и mainnet

Локальная игра запускается командой `npm run dev`. Переключателя сети в HUD нет:
сеть задаётся окружением развёртывания — Development и Preview работают в
тестовой сети 46630, Production — в mainnet 4663 (task8 §17).

Страница операций находится по адресу `/token-admin.html`. Она отдаётся
серверной функцией: без действующей админ-сессии возвращается только форма
входа, а разметка консоли не покидает сервер. Админ-API защищён независимо от
страницы — сессия, CSRF-токен, проверка origin, rate limit, `no-store` и
`noindex`. Адрес ERC-20 контракта проверяется на выбранной сети через RPC
(`eth_getCode`, `name`, `symbol`, `decimals`, `totalSupply`, `balanceOf`),
конфигурация версионируется, а активация требует второго подтверждения фразой.
Все действия попадают в аудит без подписей, ключей и секретов.

Поток денег разделён по границе доверия:

1. Игрок подключает свой кошелёк и подписывает одноразовый challenge (SIWE).
   Игра никогда не просит seed-фразу, приватный ключ или keystore.
2. Сервер выдаёт депозитную котировку с уникальным `depositId`; кошелёк
   подтверждает approve ровно на нужную сумму и вызывает депозитный контракт.
3. Game Coins выпускаются только после того, как backend самостоятельно
   проверил канонический `Deposited` event, сумму, кошелёк, `depositId`,
   уникальность `chainId + txHash + logIndex` и требуемый уровень расчёта
   (`safe`/`finalized`). Хеша транзакции от клиента недостаточно никогда.
4. Покупка в чужом бизнесе проходит через escrow; on-chain токены остаются в
   хранилище, а право требования переходит от покупателя продавцу — отдельная
   транзакция на каждую покупку не нужна.
5. При выводе Game Coins блокируются, серверный воркер отправляет ERC-20 из
   хранилища на проверенный связанный кошелёк, статус и ссылка на Blockscout
   видны игроку. Если транзакция так и не была отправлена, блокировка
   возвращается; повторная отправка никогда не происходит автоматически.

Приватный ключ выплат не хранится в клиенте и не попадает в `NEXT_PUBLIC_`/
`VITE_` переменные. Для mainnet требуется управляемый подписант; переменная
окружения с ключом допустима только для разработки и тестовой сети.

Историческая Solana-часть (`src/solana.js`, `src/walletProviders.js`,
`api/pool.js`, скрипты Devnet) сохранена, но не импортируется приложением;
записи Solana-кошельков помечены как исторические и не могут подписывать
транзакции Robinhood Chain. Подробности и оставшиеся ручные шаги —
в [`docs/TASK8_MIGRATION.md`](docs/TASK8_MIGRATION.md).
