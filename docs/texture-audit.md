# Texture, material and model audit — task6

Final date: 2026-08-29. The active visual stack is procedural Three.js/WebGL;
there are no imported GLB/FBX models, image texture files, decals, atlases or LOD
groups. Every mesh and map is created from stable source modules and every active
family is covered by the generated manifests.

## Complete inventory

- [`assets/ASSET_MANIFEST.csv`](assets/ASSET_MANIFEST.csv): 84 model, option,
  item and runtime-family records with dimensions/pivot, UV coverage, materials,
  texture dependencies, polygon counts, gameplay contracts, action and status.
- [`assets/TEXTURE_MANIFEST.csv`](assets/TEXTURE_MANIFEST.csv): 58 color/data/UI
  map records with resolution, storage, color space, mipmaps, wrap/filter,
  anisotropy, alpha, memory, source/license and final decision.
- [`assets/VISUAL_AUDIT.json`](assets/VISUAL_AUDIT.json): machine-readable source.

The runtime audit is generated by `src/visualAudit.js` and can be inspected with
`?visual-audit=1`. It instantiates each foundation, height, roof, window kit,
building material, signature detail, business companion and catalog item, then
reads actual BufferGeometry and material dependencies. Parametric environment,
resident and interior families are recorded as runtime-dependent because their
counts vary with player/shared-world data.

## Audit decisions

- **Replaced/improved:** all flat terrain/building/interior/furniture surface
  categories now use the controlled library in `src/materialLibrary.js`.
- **Rebuilt:** roof face material grouping; road rings; exterior/store/interior
  glass planes and frames; curved-row plot pads.
- **Kept and reconfigured:** procedural silhouettes, resident models, sky sprite,
  signs/nameplates and special emissive items. Canvas maps now share consistent
  color space, mipmaps, filtering and anisotropy.
- **Merged/reused:** repeated tile maps and material instances are cached. Item
  label textures and NFT art are shared by stable content.
- **Removed as a design pattern:** duplicated city texture generators, per-frame
  shadow refresh, transparent-by-default interiors, overlapping ring boxes and
  coplanar glass backing.
- **Unused/not present:** imported source models, normal maps, AO maps, decals,
  LODs, texture atlases, particle image files, water texture, post-processing
  passes and remote image loading.

## Technical environment

- Engine: Three.js r185; renderer: `WebGLRenderer` (WebGL2 where available).
- Build: Vite 5.4.21; target: modern desktop/mobile web browsers.
- Color: sRGB output/maps, linear data maps, ACES Filmic exposure 1.06.
- AA: renderer MSAA via `antialias:true`; no temporal/screen-space post effects.
- Camera: perspective 50°, near 0.1, far 400, gameplay distance 10–110.
- Lighting: hemisphere + warm ambient + directional sun; 30-minute day cycle.
- Shadows: PCF 2048², 20 Hz update, bias −0.00012, normal bias 0.035.
- Fog: day/night far 180–255, starts at 65%; graph mode expands far by 1.35×.
- Import/compression: runtime CanvasTexture RGBA8; no file import/streaming pipeline.
- Active quality tier: pixel ratio cap 1.75, texture size 128–512, anisotropy ≤8.
